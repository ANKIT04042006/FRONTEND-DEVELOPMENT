# 🎬 Netflix Landing Page Clone

A responsive **Netflix Landing Page Clone** built using **HTML5** and **CSS3**. This project recreates the user interface of the official Netflix homepage, focusing on layout design, responsive styling, multimedia integration, and modern UI components.

> **Note:** This project is created for educational and learning purposes only. It is not affiliated with or endorsed by Netflix.

---


## 🚀 Features

- 🎥 Netflix-inspired landing page
- 📱 Responsive design for different screen sizes
- 🌄 Hero section with background image
- 🔴 Official Netflix logo and navigation bar
- 🌐 Language selector
- 🔐 Sign In button
- 📧 Email subscription input section
- 📺 TV feature section with embedded autoplay video
- 📥 Download Offline feature section
- 💻 Watch Everywhere section with animated video
- 👧 Kids Profile section
- ❓ Frequently Asked Questions (FAQ)
- 📌 Netflix-style footer
- 🎨 Clean UI using only HTML and CSS
